## What surprised me / patterns
- The artifact publish gate has a real bug (or an interaction I don't fully understand): re-reading the live version in full, immediately before publishing with zero other tool calls in between, still got refused as stale. A second read-then-publish attempt got a *different* error ("identical content already refused"), which is internally inconsistent with the first error ("hadn't viewed"). This happened twice in two independent contexts (the background subagent, and this session directly) — worth flagging as a tool-level issue rather than assuming it's always operator error.
- The Cyber Crime portal's own citizen manual (dated 30 Aug 2019) is older than several live features (Financial Fraud tile, Suspect Repository), and its own checklist panel contradicts the manual on file-size limits (10MB vs 5MB) — a good concrete example of why the walkthrough needed to be live, not just documentation-based.
- CPGRAMS' "disposed grievances are never reopened" turned out to be portal-wide *published policy* (FAQ Q7), not an EPFO-specific quirk as the prior research session had framed it — a correction worth propagating if this shows up in a pitch deck.
