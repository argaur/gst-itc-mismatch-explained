## Decisions made this session

None architectural. This was drafting submission collateral against an already-approved and already-implemented solution, not a product decision.

## What surprised me / patterns

- `pandoc` was not on this machine's PATH even though the `document-skills:docx` skill lists it as a dependency. Fell back to extracting `word/document.xml` directly with a small Python regex pass (paragraph-by-paragraph `<w:t>` text join). Worth knowing this fallback exists and works cleanly for read-only extraction when the primary tool is missing.
- The zero-em-dash rule is easy to violate by habit even when actively aware of it, especially in header/label patterns like "Title — Subtitle" or "0:00–0:10 — Label." Checking with a `grep -c "—"` pass after drafting, rather than trusting a careful first pass, caught both misses immediately.

## Lessons learned

No new past-mistakes entry. The em-dash slip was caught and fixed within the same turn before being shown to Gaurav, which is the system working as intended (verify before delivering), not a mistake worth recording as a class.
